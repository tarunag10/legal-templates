# Contributing

Thanks for helping make public-service tools easier to use.

## Good contributions

- Improve plain-English copy.
- Add tested templates or directory entries with official sources.
- Fix accessibility issues with keyboard, screen reader, colour contrast, or layout.
- Keep tools no-backend unless a separate privacy review is opened.
- Add a safety note for every template, especially where deadlines, territory, contract terms, or eligibility rules matter.
- Avoid example data that includes real addresses, full bank details, medical records, or live case references.

## Pull request checklist

- Run `npm test`.
- Run `npm run build`.
- Check keyboard-only navigation.
- Avoid collecting personal data.
- Include or update tests for every new template, catalogue field, or generated-letter section.
